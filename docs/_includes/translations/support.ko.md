### 문제 신고 및 기능 제안

[GitHub 이슈를 작성](https://github.com/seagochen/AnnotaryCat/issues)해 주세요. 앱의 “Help › Send a problem report…”는 해당 페이지를 열고, 검토 후 첨부할 수 있는 진단 묶음을 만듭니다. 진단 묶음에는 버전, 시스템 정보, 로그만 포함됩니다. 로그에는 명령 이름, 오류 코드, 소요 시간만 기록되며 프로젝트 데이터, 파일 내용, 비밀번호는 포함되지 않습니다. 첨부하면 이슈와 파일은 공개됩니다.

### 구독

- 구매, 갱신 및 취소는 스토어에서 처리합니다. Mac App Store의 “App Store › 계정 › 구독”에서 관리합니다.
- 새 컴퓨터를 사용하거나 재설치한 경우 앱의 “Help › AnnotaryCat Pro…”에서 “구매 복원”을 선택하세요.
- 환불은 Apple에 요청하세요.

### 자주 묻는 질문

**데이터는 어디에 저장되나요?** 선택한 작업 공간 폴더에 저장됩니다. 앱은 데이터를 업로드하지 않습니다.

**Mac App Store 버전이 학습을 직접 시작하지 못하는 이유는 무엇인가요?** 스토어 버전은 시스템 샌드박스에서 실행되어 앱 외부 프로그램을 시작할 수 없습니다. AnnotaryCat이 데이터셋을 검사하고 학습 설정과 스크립트를 작성한 뒤 실행 명령을 제공합니다. 터미널에서 실행해 주세요.

**Mac App Store 버전을 재설치한 뒤 작업 공간을 다시 선택해야 하는 이유는 무엇인가요?** 샌드박스 권한은 앱 서명에 연결됩니다. 재설치하거나 버전이 바뀌면 작업 공간과 데이터셋 폴더를 다시 선택해야 할 수 있습니다.

**구독이 끝나도 데이터는 남아 있나요?** 예. Pro가 필요한 프로젝트도 계속 열람하고 내보낼 수 있습니다. 다만 다시 구독하기 전까지 수정할 수 없습니다.
