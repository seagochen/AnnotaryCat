**문제 신고 및 기능 제안:** <https://github.com/seagochen/AnnotaryCat/issues>에서 이슈를 만들어 주세요. 앱의 “도움말 › 문제 보고…”에서는 먼저 파일을 확인하고 저장 위치를 골라 진단 ZIP을 내보낼 수 있습니다. 계속 진행하면 이 페이지가 열리며, 진단 패키지를 첨부해 제출하면 됩니다. 진단 패키지에는 버전, 시스템 정보, 로그만 들어 있습니다(로그에는 명령 이름, 오류 코드, 소요 시간만 기록되며 프로젝트 데이터, 파일 내용, 비밀번호는 포함되지 않습니다). 첨부하면 이슈와 첨부 파일은 누구나 볼 수 있습니다.

**구독:**
- 구독, 갱신, 취소는 앱을 설치한 스토어에서 처리합니다:
  - Mac App Store: “App Store › 계정 › 구독”
  - Microsoft Store: <https://account.microsoft.com/services>(구매에 사용한 Microsoft 계정으로 로그인)
- 앱의 “도움말 › AnnotaryCat Pro…”에 있는 “구독 관리”를 누르면 해당 페이지가 열립니다.
- 새 컴퓨터나 재설치 후에는 구매에 사용한 계정으로 스토어에 로그인한 다음 “도움말 › AnnotaryCat Pro…”에서 “구매 복원”을 누르세요.
- 구독은 스토어마다 따로 구매하며 서로 이전되지 않습니다.
- 환불: Mac App Store는 Apple에, Microsoft Store는 Microsoft에 요청하세요(Microsoft 판매 약관과 거주 지역의 법률을 따릅니다).

**자주 묻는 질문:**
- *데이터는 어디에 저장되나요?* 기본적으로 “문서” 폴더 안의 `AnnotaryCat` 데이터 폴더입니다(Mac App Store 버전은 앱 컨테이너 안). 폴더를 연결한 프로젝트와 이전 버전에서 지정한 위치에 저장한 프로젝트는 선택한 위치에 있습니다. “환경 설정 › 저장 위치”에서 실제 경로를 확인할 수 있습니다. Windows에서 앱 설정은 `%LOCALAPPDATA%\AnnotaryCat`에, 저장한 서버와 SSH 로그인 키는 같은 개발자의 Crescent와 함께 쓰는 `%APPDATA%\homology`에 있습니다. 앱은 개발자에게 데이터를 보내지 않습니다. 원격 데이터 소스를 선택하거나 본인의 서버에서 모델을 실행할 때도 파일과 주석은 이 컴퓨터와 설정한 서버 또는 스토리지 사이에서만 전송됩니다.
- *ReID로 무엇을 할 수 있나요?* ReID는 Pro 기능입니다. 기존 Market-1501 형식의 잘라낸 이미지 데이터셋을 가져와 트랙을 보고, 쓸 수 없는 트랙을 제외하고, ID 충돌을 확인하고, 후보 쌍을 하나씩 검토해 확정한 뒤 Market-1501 또는 쌍 목록으로 내보낼 수 있습니다. 본인의 코드를 사용자 정의 모델로 학습하고 ONNX로 내보내면, 이 컴퓨터에서 특징을 추출하고 검토할 새 후보 쌍을 찾을 수 있습니다(호스트에 있는 데이터셋에서는 추출과 탐색을 지원하지 않습니다).
- *사용자 정의 모델에는 무엇이 필요한가요?* 본인의 Python 환경(이 컴퓨터 또는 본인의 SSH 서버)과 본인의 코드입니다. 앱은 템플릿을 제공하고 코드와 데이터 복사, 실행 시작, 결과 가져오기를 맡으며, 앱 안에서 학습하지 않습니다. Mac App Store 버전은 원격 서버의 환경만 사용할 수 있습니다.
- *Mac App Store 버전을 다시 설치하면 데이터셋 폴더를 다시 선택해야 하나요?* 샌드박스 권한은 앱의 서명에 연결되어 있어, 재설치하거나 버전을 바꾼 뒤에는 연결한 데이터셋 폴더를 다시 선택해야 할 수 있습니다.
- *구독이 끝나도 데이터가 남아 있나요?* 네. Pro가 필요한 프로젝트도 보고 내보낼 수 있지만, 다시 구독하기 전까지는 수정할 수 없습니다.
