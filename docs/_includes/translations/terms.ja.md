### 1. 無料プランと Pro

AnnotaryCat は無料で利用できます。無料プランはローカルデータの物体検出と画像キャプションに対応し、プロジェクト数の制限はありません。AnnotaryCat Pro は自動更新のサブスクリプションで、このリリースの画像分類、画像セグメンテーション、ReID データセットの整理、ローカルのマジックワンド、リモートデータソース（ご自身の SSH サーバーまたは S3 ストレージ）、カスタムモデル（ご自身のトレーニングコードをこのコンピューターまたはご自身のサーバーで実行し、バージョンを管理して事前ラベル付けに使う機能）、コードエディター、制御チャネルと MCP、カスタムフィールドを解放します。AnnotaryCat は Mac App Store と Microsoft Store で提供しています。サブスクリプションはストアごとに購入するもので、もう一方のストアには引き継がれません。未提供のタスクや今後の機能は、このリリースのサブスクリプションの内容として約束するものではありません。対象機能はアプリ内の「AnnotaryCat Pro」ページをご確認ください。

### 2. 購入と支払い

月額または年額のサブスクリプションを、アプリをインストールしたストアで購入します。

- **Mac App Store**：購入確定時に Apple があなたの Apple アカウントへ請求します。
- **Microsoft Store**：Microsoft がご自身の Microsoft アカウントに登録された支払い方法へ請求します。購入には有効な支払い方法が必要です。

価格は購入画面の表示が適用され、地域や税金により異なる場合があります。私たちは支払い情報にアクセスしません。

**無料トライアル。** 各サブスクリプションには 1 週間の無料トライアルが付き、対象となる場合にのみアプリの「AnnotaryCat Pro」ページに表示されます。トライアル期間中は料金はかかりません。

- **Mac App Store**：対象は AnnotaryCat Pro のサブスクリプショングループで無料トライアルをまだ利用していないアカウントです。トライアル終了の 24 時間前までに解約しない限り、終了時にサブスクリプションが開始され、表示された料金が請求されます。
- **Microsoft Store**：無料トライアルは、お客様 1 人につき各サブスクリプション（月額・年額）で 1 回までです。トライアル終了前に解約しない限り、終了時に有料サブスクリプションへ自動的に切り替わり、最初の期間の料金が支払い方法に請求されます。

トライアル期間中に解約した場合も、Pro はトライアル終了まで利用できます。

### 3. 自動更新と解約

**Mac App Store**

- 現在の期間が終了する 24 時間前までに解約しない限り、サブスクリプションは同じ期間・その時点の価格で自動更新されます。更新料金は期間終了前の 24 時間以内に請求されます。
- 「App Store › アカウント › サブスクリプション」でいつでも管理・解約できます。解約後も、現在の期間が終了するまで Pro は有効です。

**Microsoft Store**

- サブスクリプションは解約するまで同じ期間で自動更新されます。次の期間の料金は現在の期間中に請求されます。
- 購入に使った Microsoft アカウントで <https://account.microsoft.com/services> にサインインすれば、いつでも管理・解約でき、支払い方法も変更できます。アプリの「ヘルプ › AnnotaryCat Pro…」にある「サブスクリプションを管理」からこのページが開きます。解約後も現在の期間が終了するまで Pro は有効で、その後は請求されません。
- 更新の支払いに失敗した場合、Microsoft は現在の期間中に再試行します。期間終了時点でも支払いができなければ、サブスクリプションは解約されます。
- 月額と年額の間で直接切り替えることはできません。現在のサブスクリプションを解約し、終了してからもう一方を購入してください。

### 4. 返金

- **Mac App Store**：返金は Apple のポリシーに従います。Apple にお問い合わせください。
- **Microsoft Store**：返金は Microsoft Store の販売条件とお住まいの地域の法律に従います。Microsoft にお問い合わせください。解約しただけでは、すでに請求された現在の期間の料金は返金されません。

私たちはストアの支払いや返金を処理できません。

### 5. サブスクリプション終了後

サブスクリプションが終了すると無料プランに戻ります。データは削除されません。Pro が必要なプロジェクトも開いて閲覧・エクスポートできますが、再度購読するまで変更はできません。
