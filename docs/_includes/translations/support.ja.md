**不具合の報告・機能の提案：** <https://github.com/seagochen/AnnotaryCat/issues> で Issue を作成してください。アプリの「ヘルプ › 問題を報告…」では、まずファイルを確認し、保存場所を選んで診断用の ZIP を書き出せます。続けて報告を選ぶとこのページが開くので、診断パッケージを添付して送信してください。診断パッケージにはバージョン、システム情報、ログのみが含まれます（ログにはコマンド名、エラーコード、所要時間だけが記録され、プロジェクトのデータ、ファイルの内容、パスワードは含まれません）。添付すると、Issue と添付ファイルは誰でも閲覧できるようになります。

**サブスクリプション：**
- 購読、更新、解約はアプリをインストールしたストアで行います：
  - Mac App Store：「App Store › アカウント › サブスクリプション」
  - Microsoft Store：<https://account.microsoft.com/services>（購入に使った Microsoft アカウントでサインイン）
- アプリの「ヘルプ › AnnotaryCat Pro…」にある「サブスクリプションを管理」から該当するページが開きます。
- 新しいコンピューターや再インストール後は、購入に使ったアカウントでストアにサインインし、「ヘルプ › AnnotaryCat Pro…」で「購入を復元」を押してください。
- サブスクリプションはストアごとに購入するもので、互いに引き継がれません。
- 返金：Mac App Store は Apple に、Microsoft Store は Microsoft にお問い合わせください（Microsoft の販売条件とお住まいの地域の法律に従います）。

**よくある質問：**
- *データはどこに保存されますか？* 既定では「ドキュメント」フォルダー内の `AnnotaryCat` データフォルダーです（Mac App Store 版はアプリのコンテナー内）。フォルダーをリンクしたプロジェクトや、旧バージョンで指定した場所に保存したプロジェクトは、選んだ場所にあります。「環境設定 › 保存場所」に実際のパスが表示されます。Windows では、アプリの設定は `%LOCALAPPDATA%\AnnotaryCat` に、保存したサーバーと SSH ログインキーは同じ開発者の Crescent と共用する `%APPDATA%\homology` にあります。アプリが開発者にデータを送ることはありません。リモートデータソースを選んだり、ご自身のサーバーでモデルを実行したりする場合も、ファイルとアノテーションはこのコンピューターと設定したサーバーまたはストレージの間だけで転送されます。
- *ReID では何ができますか？* ReID は Pro の機能です。既存の Market-1501 形式の切り抜きデータセットを読み込み、トラックを閲覧し、使えないトラックを除外し、ID の矛盾を確認し、候補ペアを 1 組ずつレビューして確定したうえで、Market-1501 またはペアリストとして書き出せます。ご自身のコードをカスタムモデルとして学習し ONNX に書き出せば、このコンピューターで特徴を抽出し、レビュー用の新しい候補ペアを探索できます（ホスト上のデータセットでは抽出と探索はできません）。
- *カスタムモデルには何が必要ですか？* ご自身の Python 環境（このコンピューターまたはご自身の SSH サーバー）とご自身のコードです。アプリはテンプレートを用意し、コードとデータのコピー、実行の開始、結果の取得を行いますが、アプリの中で学習はしません。Mac App Store 版はリモートサーバー上の環境のみ使えます。
- *Mac App Store 版を再インストールすると、データセットフォルダーをもう一度選ぶ必要がありますか？* サンドボックスの権限はアプリの署名に結び付いているため、再インストールやバージョン変更の後は、リンクしたデータセットフォルダーを選び直す必要がある場合があります。
- *サブスクリプションが終了してもデータは残りますか？* 残ります。Pro が必要なプロジェクトも閲覧・エクスポートできますが、再度購読するまで変更はできません。
