**AnnotaryCat은 어떠한 데이터도 수집하지 않습니다.** 사용자 데이터를 수신하는 서버를 운영하지 않습니다. 계정, 클라우드 저장소, 원격 측정, 사용 통계, 광고, 타사 분석 또는 충돌 보고 SDK가 없습니다.

### 로컬 주석 작업은 완전히 오프라인으로 가능합니다

앱 시작과 로컬 데이터의 주석 작성, 저장, 내보내기에는 네트워크가 필요하지 않습니다. 앱은 자동으로 외부 네트워크 요청을 보내지 않으며 업데이트 확인, 원격 측정, 자동 충돌 보고도 없습니다. 시작할 때 모델, 글꼴 또는 실행 의존성을 다운로드하지 않습니다. 이 설명은 로컬 주석 기능에 적용됩니다. 사용자가 설정하여 사용하는 원격 기능, 시스템 스토어 서비스, 직접 여는 브라우저와 외부 프로그램에는 아래의 범위가 적용됩니다.

### 데이터 저장 위치

- 이미지, 동영상, 텍스트, 주석 및 프로젝트 설정은 사용자가 선택한 작업 공간 폴더에 저장됩니다. 이 폴더는 사용자 컴퓨터나 연결한 디스크에 있습니다.
- 앱 자체 설정, 로그, 충돌 기록 및 로그인 키는 이 컴퓨터의 사용자 설정 디렉터리에만 저장됩니다. macOS 샌드박스 버전에서는 앱 컨테이너 안에 저장됩니다.
- 로그에는 명령 이름, 오류 코드 및 소요 시간만 기록합니다. 프로젝트 데이터, 주석, 파일 내용, 매개변수 값 또는 비밀번호는 기록하지 않습니다. 홈 디렉터리는 로그에서 `~`로 표시됩니다.

### 데이터가 컴퓨터 밖으로 나가는 경우

사용자가 명시적으로 요청한 경우에만, 사용자가 선택한 목적지로만 전송됩니다.

- **사용자 소유 SSH 서버:** 데이터셋이 원격 호스트에 있으면 시스템의 `ssh` / `sftp`로 지정한 호스트에 연결합니다.
- **사용자가 연결한 AI 도구:** 제어 채널 또는 MCP를 켜면 이 컴퓨터에서 실행하는 AI 도구가 허용한 프로젝트와 폴더를 읽고 쓸 수 있습니다. 해당 도구의 데이터 전송 목적지는 사용하는 AI 서비스에 따라 달라집니다. AI 접근은 프로젝트별로 끌 수 있습니다.
- **문제 보고:** 앱은 자동으로 아무것도 전송하지 않습니다. “문제 보고 보내기”를 선택하면 브라우저에서 GitHub 이슈 페이지를 엽니다. 진단 묶음을 검토한 뒤 첨부 여부를 직접 결정합니다. 첨부하면 이슈와 파일은 공개되며 GitHub 개인정보 처리방침이 적용됩니다.
- **설정한 S3 / S3 호환 저장소:** 원격 데이터셋을 설정하여 사용할 때 설치된 AWS CLI가 선택한 bucket, endpoint 및 자격 증명 설정에 따라 저장소와 인증 서비스에 접근합니다. 요청은 당사 서버를 거치지 않습니다.
- **직접 여는 웹페이지:** 약관, 개인정보 처리방침, 구독 관리 링크는 사용자가 선택할 때만 시스템 브라우저에서 열립니다. 네트워크 요청은 페이지 제공자가 처리합니다.

제어 채널은 `127.0.0.1`에서만 수신합니다. MCP는 로컬 표준 입출력을 사용하며, 열린 창에 연결할 때는 루프백을 사용합니다. SSH 비밀번호 도우미도 루프백만 사용합니다. 이 통신은 다른 컴퓨터에 서비스를 노출하거나 당사 서버로 데이터를 업로드하지 않습니다.

### 스토어 서비스

인앱 구매는 시스템 스토어 API를 사용합니다(현재 macOS에서는 StoreKit 2). 구매, 복원, 상품 및 구독 상태 조회 시 시스템 서비스가 스토어 운영자와 통신할 수 있습니다. 앱은 자체 온라인 라이선스 검증을 구현하지 않으며 요청을 당사 서버로 보내거나 거래에 주석 데이터를 첨부하지 않습니다. 거래에는 스토어 운영자의 개인정보 처리방침이 적용됩니다. 시스템 스토어, 운영체제, 브라우저 및 사용자가 실행하는 외부 도구의 네트워크 동작은 위 로컬 주석 기능의 오프라인 설명에 포함되지 않습니다.

### 비밀번호 및 키

- SSH 비밀번호는 한 번만 사용하고 저장하지 않습니다.
- “앞으로 자동 연결”을 선택하여 만든 로그인 키는 이 컴퓨터에만 저장되며 사용자 계정만 읽을 수 있습니다.
- 향후 API 토큰을 지원하는 경우 시스템 키체인에 저장됩니다.
- 비밀번호, 키, 토큰은 프로젝트 파일, 로그 또는 명령 결과에 기록되지 않습니다.
