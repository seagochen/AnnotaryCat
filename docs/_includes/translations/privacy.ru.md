**AnnotaryCat не собирает никаких данных.** У нас нет сервера, принимающего ваши данные: нет учётных записей, облачного хранилища, телеметрии, статистики использования, рекламы и сторонних SDK для аналитики или отправки отчётов о сбоях.

### Локальная разметка полностью работает без интернета

Запуск приложения, разметка, сохранение и экспорт локальных данных не требуют сети. Приложение не выполняет автоматических внешних запросов: нет проверки обновлений, телеметрии или автоматической отправки отчётов о сбоях. При запуске не загружаются модели, шрифты и зависимости среды выполнения. Это заявление относится к локальной разметке; для настроенных и используемых вами удалённых функций, системных служб магазина, открываемого браузера и внешних программ действуют границы, описанные ниже.

### Где хранятся ваши данные

- Изображения, видео, текст, разметка и настройки проектов остаются в выбранной рабочей папке на вашем компьютере или подключённом диске.
- Настройки приложения, журналы, записи о сбоях и ключи входа остаются в каталоге настроек вашего пользователя на этом компьютере. В изолированной версии для macOS они находятся в контейнере приложения.
- В журналах сохраняются только названия команд, коды ошибок и длительность выполнения. Данные проектов, разметка, содержимое файлов, значения параметров и пароли не записываются. Домашний каталог отображается как `~`.

### Когда данные покидают компьютер

Только по вашему явному запросу и только выбранному вами получателю:

- **Ваш собственный SSH-сервер.** Если набор данных находится на удалённом хосте, приложение подключается к указанному вами хосту через системные `ssh` / `sftp`.
- **Подключённые вами инструменты ИИ.** При включении канала управления или MCP инструменты ИИ, запущенные на этом компьютере, могут читать и изменять разрешённые вами проекты и папки. Куда эти инструменты отправляют данные, зависит от используемого сервиса ИИ. Доступ ИИ можно отключать для каждого проекта отдельно.
- **Сообщения о проблемах.** Приложение ничего не отправляет автоматически. При выборе «Отправить сообщение о проблеме» в браузере открывается страница задачи GitHub. Вы проверяете диагностический архив и решаете, прикреплять ли его. После прикрепления задача и вложения становятся общедоступными; к ним применяется политика конфиденциальности GitHub.
- **Настроенное вами хранилище S3 / совместимое с S3.** При настройке и использовании удалённого набора данных приложение запускает установленный вами AWS CLI для доступа к хранилищу и службам аутентификации согласно выбранным bucket, endpoint и настройкам учётных данных. Запросы не проходят через наши серверы.
- **Открываемые вами веб-страницы.** Ссылки на условия, конфиденциальность и управление подпиской открываются в системном браузере только по вашему выбору. Сетевые запросы обрабатывает поставщик страницы.

Канал управления слушает только `127.0.0.1`; MCP использует локальные стандартные потоки ввода/вывода (или loopback при подключении к открытому окну). Помощник паролей SSH также использует только loopback. Эти соединения не открывают службу другим компьютерам и не отправляют данные на наши серверы.

### Службы магазина

Встроенные покупки используют системные API магазина (сейчас StoreKit 2 в macOS). При покупке, восстановлении и запросе товаров или статуса подписки системные службы могут связываться с оператором магазина. Приложение не выполняет собственную сетевую проверку лицензии, не направляет запросы через наши серверы и не прикладывает данные разметки к транзакциям. Оператор обрабатывает транзакции согласно своей политике конфиденциальности. Сетевая активность магазина, операционной системы, браузера и запускаемых вами внешних инструментов не относится к заявлению об автономной локальной разметке.

### Пароли и ключи

- Пароль SSH используется один раз и не сохраняется.
- Ключ входа, созданный при выборе автоматического подключения, остаётся на этом компьютере и доступен для чтения только вашей учётной записи пользователя.
- Если в будущем появится поддержка токенов API, они будут храниться в системной связке ключей.
- Пароли, ключи и токены никогда не записываются в файлы проектов, журналы или результаты команд.

### Дети

Приложение не собирает информацию о детях, поскольку не собирает никакой информации вообще.
