**AnnotaryCat はデータを一切収集しません。** データを受信するサーバーは運営していません。アカウント、クラウドストレージ、テレメトリー、利用統計、広告、第三者の分析・クラッシュ報告 SDK はありません。

### データの保存先

- 画像、動画、テキスト、アノテーション、プロジェクト設定は、あなたが選ぶワークスペースフォルダーに保存されます。保存先は自分のパソコンまたはマウントしたディスクです。
- アプリの設定、ログ、クラッシュ記録、ログイン鍵は、このパソコンのユーザー設定ディレクトリにのみ保存されます。macOS のサンドボックス版ではアプリのコンテナ内にあります。
- ログに記録するのはコマンド名、エラーコード、所要時間だけです。プロジェクトデータ、アノテーション、ファイル内容、パラメーター値、パスワードは記録しません。ホームディレクトリはログで `~` と表示されます。

### データがパソコンの外へ出る場合

あなたが明示的に指示した場合に限り、あなたが選ぶ宛先に送信します。

- **あなた自身の SSH サーバー：** データセットがリモートホストにある場合、システムの `ssh` / `sftp` を使って指定のホストに接続します。
- **あなたが接続する AI ツール：** 制御チャネルや MCP を有効にすると、このパソコン上で実行する AI ツールは許可されたプロジェクトやフォルダーを読み書きできます。そのツールがデータをどこへ送信するかは、利用する AI サービスによります。AI アクセスはプロジェクトごとに無効にできます。
- **不具合報告：** アプリは自動送信しません。「問題を報告」を選ぶとブラウザーで GitHub の Issue ページが開きます。診断パッケージを確認し、添付するかどうかはあなたが決めます。添付後、Issue とファイルは公開され、GitHub のプライバシーポリシーが適用されます。

### パスワードと鍵

- SSH パスワードは一度だけ使用し、保存しません。
- 「今後は自動接続」を選んで作成したログイン鍵はこのパソコンに保存され、あなたのユーザーアカウントだけが読み取れます。
- 将来 API トークンに対応する場合は、システムのキーチェーンに保存します。
- パスワード、鍵、トークンはプロジェクトファイル、ログ、コマンドの結果に書き込みません。

### 子どもについて

本アプリは情報を一切収集しないため、子どもの情報も収集しません。
